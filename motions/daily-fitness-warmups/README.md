# Daily 健身热身

适用于 Daily 的健身场景热身动作扩展，统一使用粉色运动上衣、粉色头带、暖白运动裤和瑜伽垫器材组合。

包含 1 个循环训练动作和 4 个一次性动作：

- `daily-fitness-shoulder-warmup`：肩臂绕环热身
- `daily-fitness-side-stretch`：左右侧腰拉伸
- `daily-fitness-lunge-warmup`：弓步压腿
- `daily-fitness-water-break`：拿起水壶、喝水并放回原位
- `daily-fitness-curl-loop`：持续双手哑铃弯举

`daily-fitness-curl-loop` 适合作为健身状态的背景动作；一次性动作结束后，由 Everby 恢复当前状态配置的背景动作。其他动作可以绑定点击、对话或提醒事件。
