# Daily 户外羽毛球

适用于 Daily 的户外羽毛球动作扩展。造型统一使用白色运动上衣、暖白运动裙裤、粉色头带和深灰球拍，场景只保留浅蓝色局部球场与白色边线。

包含 6 个动作：

- `daily-badminton-ready-loop`：球场待机循环
- `daily-badminton-serve`：低手发球
- `daily-badminton-forehand`：正手击球
- `daily-badminton-smash`：跃起扣杀
- `daily-badminton-cheer`：得分庆祝
- `daily-badminton-side-step`：侧向垫步移动循环

建议把“球场待机”设为状态待机动画，把“侧向垫步”绑定移动语义，其余动作可加入状态动作池或绑定点击、对话事件。
